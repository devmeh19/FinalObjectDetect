# 🎯 Object Detection System

A real-time object detection system using deep learning models integrated with OpenCV. The application detects and classifies objects in images, video streams, or webcam input.

---

## 📦 Features

- Real-time object detection using pre-trained models (YOLOv5 / SSD / Faster R-CNN)
- Bounding box and class label overlay
- Webcam/video/image support
- Optional confidence threshold control
- Supports multiple object classes

---

## 🛠 Tech Stack

- Python
- OpenCV
- PyTorch / TensorFlow (based on model)
- YOLOv5 / SSD / COCO Dataset
